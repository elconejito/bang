HANDOFF NOTES · NOT UI
Selection scope. Select all covers only selectable rows in the current pagination response. Selection clears on page, page size, search, state, location, lifecycle, sort, group change, and on exiting bulk mode. No separate 100-item cap — page size is the ceiling.
Row vs checkbox. Only the checkbox is focusable and exposes role="checkbox" + aria-checked. Row click is a pointer-only convenience; the row is not a second tab stop, so keyboard and AT behaviour stays unambiguous. Rows carry aria-selected.
Announcements. A polite live region announces selected count changes, clears, saving, and completion. Select all exposes the indeterminate state via aria-checked="mixed".
Warnings. Every caution and group-change treatment pairs colour with an icon and explicit text. Focus moves to the drawer heading on open and returns to the Bulk edit trigger on close.
